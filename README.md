# U1 Core

**Architecture index for the Unmute1AI platform.**

U1 Core is the coordination layer for the broader Unmute1AI portfolio. It documents how accessibility, cognition, verification, authorization, and recovery components fit together.

## Platform map

- **OmniSign** — accessible sign/gesture communication
- **SIGNAL** — multimodal communication and intent layer
- **Sentinel / Glass Box** — external authority control and reproducible evidence
- **AnnealMesh** — candidate reasoning verification
- **Phoenyx Ignis** — governed recovery environment
- **AEGIS-Q** — NVIDIA-edge embodied security model scaffold
- **Myelin** — typed API/platform infrastructure
- **EMS Guardian / Clinical Sign / Telehealth** — domain-specific accessible communication concepts

## Design rule

> Intelligence may change. Authority does not.

Model capability, evaluator confidence, or external scanner results do not create permission to perform consequential effects.

## Status

**Architecture/documentation repository.** There is no deployable runtime in this repository yet. Production services live in their respective repositories.
